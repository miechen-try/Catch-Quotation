Catch-Quotation 使用說明

本版本新增「PDF 文字可選取／手動補抓」功能。

1. 上傳 PDF 後，左側 PDF 預覽會建立可選取的文字層。
2. 如果自動判讀某個欄位不完整，可以直接在左側 PDF 預覽用滑鼠拖曳選取文字，按 Ctrl+C。
3. 你可以直接把選到的文字貼到右側「故障原因／廠商檢測回覆／更換零件料號／品名／數量／未稅報價」等欄位。
4. 也可以把整段 PDF 文字貼到「PDF 內容手動補抓」區塊，再按「用貼上內容重新判讀」，系統會用貼上的內容重新解析，並只覆蓋成功判讀的欄位。
5. 「複製目前 PDF 文字」可以把目前 PDF.js 擷取到的完整文字複製到剪貼簿。
6. 右側欄位仍可直接手動修改。
7. 「複製到 Google Sheet」會依目前畫面欄位產生貼上資料。
8. 多個零件會拆成多列。
9. 型號會依指定對照表轉換成 Google Sheet 用名稱。
10. 報價單檔名複製按鈕會複製畫面上目前的修改後檔名。

GitHub Pages 更新：
請將 index.html、app.js、style.css 三個檔案放在 GitHub 專案根目錄，取代舊檔。
更新後建議等待 1~2 分鐘，再使用 Ctrl+F5 強制重新整理。
