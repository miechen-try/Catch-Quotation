【GitHub 更新方式】
1. 將本資料夾的 index.html、app.js、style.css 上傳並取代 GitHub Pages 專案根目錄同名檔案。
2. 不要只上傳 app(6).js、app(7).js 等其他檔名；index.html 實際載入的是 app.js。
3. 本版已在 index.html 對 CSS / JS 加版本參數，降低瀏覽器快取造成「GitHub 已更新但畫面沒變」的問題。
4. GitHub Commit 後，等待 Pages 部署完成，再使用 Ctrl+F5 強制重新整理。

【Google Sheet 貼上】
請在 Google Sheet 的 B 欄第一格貼上。
B 案件編號
C SR單號
D 填寫日期
E 空白
F 門市名稱
G 報修設備（依指定型號對照表）
H 設備序號
I 故障原因
J 廠商檢測回覆
K 收費方式（預設：耗材收費）
L 更換零件料號
M 更換零件品名
N 更換零件數量
O 未稅報價

多個零件會自動拆成多列，共同欄位會在每一列重複。
